# NetSplice
SelectiveNetwork control. Control where Internet connections are goingDirect or indirect

## Tools

- [`netscope/`](netscope/) — monitor and control an Android or iOS phone over Wi-Fi/Tailscale (screen, CPU, memory, FPS, logs) with nothing installed on the phone.
- [`ios/`](ios/) — native iPhone/iPad app for NetScope: view the screen, metrics and logs, and control the test phone from your own phone over Wi-Fi/Tailscale.
